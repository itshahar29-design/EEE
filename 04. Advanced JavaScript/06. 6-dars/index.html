RegEx (Regular Expressions): Muntazam Ifodalar va Validatsiya

Matn qoliplari (/pattern/), test(), match(), replace() metodlari, email va telefon raqam formatini tekshirish.

🔍 1. RegEx Nima?

RegEx (Regular Expression) — matn ichida ma'lum bir qolipga (pattern) mos keluvchi belgilarni qidirish, tekshirish va almashtirish uchun kuchli vosita.

const emailRegex = /^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$/;
console.log(emailRegex.test("user@gmail.com")); // true
console.log(emailRegex.test("not-an-email"));    // false

📑 2. Asosiy RegEx Belgilari

  • \d — Har qanday raqam (0-9).
  • \w — Harf yoki raqam yoki pastki chiziq.
  • \s — Bo'sh joy (probel).
  • + — 1 yoki undan ko'p marta takrorlanish.
  • * — 0 yoki undan ko'p marta takrorlanish.
