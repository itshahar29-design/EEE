# 230. Global Energiya Sarfi va Qayta Tiklanuvchi Manbalar Xaritasi

## Tavsif
**Global Energiya Sarfi va Qayta Tiklanuvchi Manbalar Xaritasi** — Data visualization toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Mintaqalar bo'yicha quyosh, shamol va gidroenergiya ulushini SVG xaritasida ko'rish**
- **Yillar kesimida toza energiyaga o'tish dinamikasi va emissiya kamayishi**
- **Mamlakatlar bo'yicha qidiruv va ko'rsatkichlarni taqqoslash paneli**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Interactive SVG Map
- Energy Stats
- Charts

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
