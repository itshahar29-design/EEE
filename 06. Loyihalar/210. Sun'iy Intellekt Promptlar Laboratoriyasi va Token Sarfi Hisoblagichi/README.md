# 210. Sun'iy Intellekt Promptlar Laboratoriyasi va Token Sarfi Hisoblagichi

## Tavsif
**Sun'iy Intellekt Promptlar Laboratoriyasi va Token Sarfi Hisoblagichi** — CRM/To-do toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Tizimli prompt shablonlarini toifalar (Kodlash, Matn, Marketing) bo'yicha saqlash**
- **Kiritilgan matn uchun taxminiy tokenlar soni va narxini hisoblovchi kalkulyator**
- **Promptlarni nusxalash, sinovdan o'tkazish va versiyalarini boshqarish**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Token Estimation
- Prompt Engineering
- LocalStorage

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
