# 207. Markdown Texnik Hujjatlar Muharriri va Jonli HTML Eksport

## Tavsif
**Markdown Texnik Hujjatlar Muharriri va Jonli HTML Eksport** — Editor toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Matn kiritilganda bir zumda HTML preview ga aylantiruvchi ikki oynali tahrirchi**
- **So'zlar, belgilar va o'qish vaqti sonini hisoblovchi jonli statistika**
- **Hujjatni Markdown (.md) va toza HTML (.html) formatlarida fayl qilib yuklab olish**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Markdown Parser
- Live Preview
- LocalStorage

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
