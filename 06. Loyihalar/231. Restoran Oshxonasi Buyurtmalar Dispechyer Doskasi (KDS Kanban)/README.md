# 231. Restoran Oshxonasi Buyurtmalar Dispechyer Doskasi (KDS Kanban)

## Tavsif
**Restoran Oshxonasi Buyurtmalar Dispechyer Doskasi (KDS Kanban)** — Kanban toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Yangi, Tayyorlanmoqda va Yetkazishga Tayyor ustunlari bo'ylab buyurtmalar**
- **Har bir stol buyurtmasi uchun tayyorlash vaqti sanagichi va kechikish ogohlantirishi**
- **Oshpaz tomonidan bitta tugma bilan buyurtma holatini keyingi bosqichga o'tkazish**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Order Dispatch
- Timer Countdown
- Kitchen KDS

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
