# 219. Fitnes Mashg'ulotlar Rejalashtiruvchisi va Kaloriya Sarfi Diagrammasi

## Tavsif
**Fitnes Mashg'ulotlar Rejalashtiruvchisi va Kaloriya Sarfi Diagrammasi** — CRM/To-do toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Kunlik mashg'ulotlar (Kardio, Kuch, Cho'zilish) ro'yxati va taymer**
- **Sarflangan kaloriyalarni haftalik SVG diagrammada tahlil qilish**
- **Kunlik ichilgan suv miqdori va maqsadga erishish foiz sanagichi**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Calorie Tracker
- SVG Progress
- LocalStorage

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
