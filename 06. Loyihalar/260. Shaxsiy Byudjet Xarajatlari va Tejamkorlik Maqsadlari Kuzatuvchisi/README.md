# 260. Shaxsiy Byudjet Xarajatlari va Tejamkorlik Maqsadlari Kuzatuvchisi

## Tavsif
**Shaxsiy Byudjet Xarajatlari va Tejamkorlik Maqsadlari Kuzatuvchisi** — CRM/To-do toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Oylik maosh, qo'shimcha daromadlar va xarajatlar toifalari bo'yicha hisob**
- **Orzudagi xaridlar (Uy, Avtomobil, Sayohat) uchun jamg'arma foizi sanagichi**
- **Haftalik xarajatlar limitdan oshib ketganda sariq va qizil ogohlantirish**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Budget Tracker
- Savings Goals
- SVG Progress

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
