# 259. Dunyo Poytaxtlari Jonli Vaqt Mintaqalari va Quyosh Chiqishi API

## Tavsif
**Dunyo Poytaxtlari Jonli Vaqt Mintaqalari va Quyosh Chiqishi API** — API loyihalar toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Toshkent, London, Nyu-York, Tokio shaharlarining real vaqtdagi analog soatlari**
- **Quyosh chiqishi, botishi va kun uzunligi bo'yicha astronomik ko'rsatkichlar**
- **Shahar nomi bo'yicha tezkor qidiruv va yangi poytaxtni qo'shish**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- World Clock
- Timezone API
- Analog Canvas

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
