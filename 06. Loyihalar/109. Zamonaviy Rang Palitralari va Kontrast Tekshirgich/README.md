# Zamonaviy Rang Palitralari va Kontrast Tekshirgich

## 📌 Umumiy Tavsif
Ushbu loyiha **EduMemory Pro Frontend Platformasi**ning **№109** raqamli amaliy portfolio loyihasidir.

- **Kategoriya:** Editor
- **Daraja:** Boshlang'ich (Foundation)
- **Mo'ljallangan vaqt:** 45 daqiqa

## 🚀 Asosiy Imkoniyatlar
- Probel (Spacebar) bosganda uyg'un ranglar palitrasini generatsiya qilish
- WCAG 2.1 bo'yicha matn va fon kontrasti (AAA, AA) reytingi
- Ranglarni HEX, RGB, HSL formatda nusxalash va saqlash

## 🛠️ Ishlatilgan Texnologiyalar
- HTML5
- CSS3
- JavaScript
- WCAG Contrast API

## 💻 Mahalliy Kompyuterda Ishga Tushirish
1. Ushbu papkani oching.
2. `index.html` faylini ixtiyoriy zamonaviy brauzerda oching.
3. Barcha funksiyalar to'liq avtonom va mahalliy (offline) ishlaydi.
