## 🚀 Asosiy Imkoniyatlar
- Vazifalarni ustunlar bo'ylab sudrab ko'chirish (Drag & Drop)
- Vazifa muhimlik darajalari (Past, O'rta, Yuqori) va teglari
- LocalStorage da to'liq saqlash va qidiruv bo'yicha saralash

## 🛠️ Ishlatilgan Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Drag-Drop
- LocalStorage

1. Ushbu papkani oching.
2. `index.html` faylini ixtiyoriy zamonaviy brauzerda oching.
3. Barcha funksiyalar to'liq avtonom va mahalliy (offline) ishlaydi.
