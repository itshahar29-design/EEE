# 251. Real-Vaqt Birja Qimmatli Qog'ozlar Portfeli va Risklar Tahlili

## Tavsif
**Real-Vaqt Birja Qimmatli Qog'ozlar Portfeli va Risklar Tahlili** — Dashboard toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Aktivlar (Aksiyalar, Obligatsiyalar, Kripto) bo'yicha diversifikatsiya diagrammasi**
- **Foyda va zararlar (P&L) hisoblagichi hamda volatilite risk ko'rsatkichi**
- **Yangi aksiyalarni qo'shish va bozor narxlari simulyatsiyasi**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Stock Portfolio
- SVG Risk Matrix
- LocalStorage

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
