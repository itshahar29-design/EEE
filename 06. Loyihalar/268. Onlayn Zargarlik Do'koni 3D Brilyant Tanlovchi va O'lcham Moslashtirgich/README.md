# 268. Onlayn Zargarlik Do'koni 3D Brilyant Tanlovchi va O'lcham Moslashtirgich

## Tavsif
**Onlayn Zargarlik Do'koni 3D Brilyant Tanlovchi va O'lcham Moslashtirgich** — E-commerce toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Brilyant qirralari (Dumaloq, Malika, Zumrad) va metall turi (Oltin, Platina) tanlovi**
- **Barmog'ingizga mos uzuk o'lchamini topuvchi interaktiv vizual o'lchov vositasi**
- **Karat, soflik va rang parametrlariga qarab narxni lahzada hisoblash**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Jewelry Showcase
- Ring Size Finder
- Store

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
