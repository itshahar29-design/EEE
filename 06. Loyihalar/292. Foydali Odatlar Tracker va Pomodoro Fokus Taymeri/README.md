# 292. Foydali Odatlar Tracker va Pomodoro Fokus Taymeri

## Tavsif
**Foydali Odatlar Tracker va Pomodoro Fokus Taymeri** — CRM/To-do toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **25 daqiqa ish va 5 daqiqa dam olish Pomodoro intervallari taymeri**
- **Vaqt tugaganda ovozli signal va brauzer bildirishnomasi**
- **Kun davomida bajarilgan fokus seanslari soni va odatlar hisoboti**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Pomodoro Timer
- Habit List
- Sound Alert

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
