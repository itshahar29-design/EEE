# 258. Mahsulot Yo'l Xaritasi (Roadmap) va Kvartal Rejalari Boshqaruvi

## Tavsif
**Mahsulot Yo'l Xaritasi (Roadmap) va Kvartal Rejalari Boshqaruvi** — Kanban toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Q1, Q2, Q3 va Q4 kvartallari bo'ylab strategik vazifalar taqsimoti**
- **Vazifalarni ustunlar va ustuvorliklar bo'yicha sudrab ko'chirish (Drag & Drop)**
- **Rivojlanish bosqichi (Tadqiqot, Ishlanma, Beta, Reliz) foiz hisoblagichi**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar

- Product Roadmap

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
