# 226. IT Ish Qidiruvchilar Uchun ATS Rezyume Skoreri va Tahlilchisi

## Tavsif
**IT Ish Qidiruvchilar Uchun ATS Rezyume Skoreri va Tahlilchisi** — Portfolio toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Rezyume matni va ish tavsifi (Job Description) orasidagi moslik foizi**
- **Yetishmayotgan muhim kalit so'zlar (React, Node, SQL va h.k.) ro'yxati**
- **Rezyumeni kuchaytirish bo'yicha avtomatik maslahatlar va tahlil hisoboti**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.
