# 248. Canvas Chizmachilik Doskasi va Shakllar Eksporti

## Tavsif
**Canvas Chizmachilik Doskasi va Shakllar Eksporti** — Editor toifasiga mansub, FrontCraft Pro platformasining professional darajadagi interaktiv frontend loyihasidir. Loyiha asinxron ma'lumotlar bilan ishlash, SVG ma'lumotlar vizualizatsiyasi, Observer arxitekturasidagi reaktiv State boshqaruvi va to'liq moslashuvchan (Responsive) interfeysni o'z ichiga oladi.

## Asosiy Imkoniyatlar
- **Qalam, o'chirg'ich, chiziq, to'rtburchak va doira shakllarini chizish**
- **Ranglar palitrasi, qalam qalinligini boshqarish va bekor qilish (Undo)**
- **Chizilgan rasmni toza PNG formatida yuklab olish**
- **Reaktiv Store**: Observer and Pub/Sub patternlari orqali markazlashtirilgan holat boshqaruvi.
- **Dinamik SVG Grafiki**: Haqiqiy matematik koordinatalar asosida chiziluvchi dinamik ustunli diagramma.
- **Form Validatsiyasi**: Xatoliklarni real vaqt rejimida aniqlovchi xavfsiz forma boshqaruvi.
- **CSV Eksport**: Kiritilgan barcha ma'lumotlarni bir bosishda fayl ko'rinishida eksport qilish.
- **Xotira (LocalStorage)**: Foydalanuvchi ma'lumotlari va tanlangan tema brauzerda doimiy saqlanadi.

## Texnologiyalar
- HTML5
- CSS3
- JavaScript
- Canvas Drawing
- Color Picker
- PNG Export

## Ishga tushirish
Hech qanday murakkab freymvorklarsiz ishlaydi:
1. `index.html` faylini istalgan zamonaviy veb-brauzerda oching.
2. Yoki mahalliy server orqali:
```bash
npx serve .
```
